# 7. НЕЗАВИСИМЫЙ SOURCE-LEVEL AUDIT — 03.09.2026

Эта проверка была проведена отдельно от пользовательских PageSpeed цифр.

### Repository

По прямому Git API:

- `main` = `fcbf3daa9d25b9a469757e21501912e903667aed`;
- reference = `046f15e4ac5dae7f6b665314b824501cc8816259`;
- working = `5fbfdf7f3d07e201f9f091f655ff6e5eb87124ab`.

Reference → working: 48 ahead / 0 behind.

### Независимо подтверждены следующие проблемы

1. **Hero priority:** `product.liquid` выставляет `loading=eager` и `fetchpriority=high` только после `DOMContentLoaded`. Это не гарантирует ранний priority hint.
2. **H1 rewrite:** `layouts.layout.liquid` post-load script превращает все H1 после первого в H2. Семантику нужно исправлять в источнике markup, а не после рендера.
3. **OG dimensions:** layout жёстко задаёт `og:image:width=1200` и `og:image:height=360` для разных типов страниц; это может не соответствовать реальным images.
4. **Fonts:** page-local Google Fonts `@import` найдены минимум в index/product/collection/cart/compare/favorite/search/blog/article/page.
5. **theme.js:** body-wide `MutationObserver` с `childList/subtree`, global capture click listener и inline style mutations. Это потенциальный P1/P2 hotspot.
6. **Product schema:** Product + AggregateOffer содержит вручную заданный minimum order «От 100 штук», при том что публичные Wood pages ранее подтверждены как «От 40 штук».
7. **404:** `page_404.liquid` показывает сообщение, но source-level не доказывает HTTP status/indexability/soft-404.
8. **CSS architecture:** `theme.scss` ≈18 KB, `index.liquid` ≈90 KB, `V2.1_HOME_APPEND.liquid` ≈88 KB; есть page-local styles + broad global selectors/`!important`.

### Standards cross-check

InSales документирует `image_url` с размером и WebP и canonical через product/collection variables. Это поддерживает image-responsive и canonical части плана. Google/web.dev рекомендуют resource hints, responsive/efficient image delivery и осторожный lazy loading для non-critical resources. OWASP рассматривает CSP/COOP как hardening mechanisms.
