# InSales: SEO и runtime

Официальный каталог: `https://www.insales.ru/collection/documentation`

## Документация, которую учитываем в проекте

В официальной документации отдельно представлены sitemap, дизайн/публикация/предпросмотр шаблонов, контент, настройки сайта и SEO.

Для VELES LEGS SEO уже имеет собственную реализацию в `head.liquid`, поэтому не следует создавать вторую параллельную SEO-систему только ради нового дизайна.

## Runtime

Документация InSales прямо показывает, что система генерирует/подключает стили и виджеты поверх шаблонов. Поэтому статический исходник не всегда описывает итоговый DOM.

Для визуальных дефектов применяется правило проекта:

`DOM → class/structure → Computed Style → CSS/JS source → сравнение с базой → точечное исправление`.

## Практический вывод

Figma QA проверяет визуальный контракт, а browser/runtime QA подтверждает фактическое поведение InSales. Одно не заменяет другое.
