## Для VELES LEGS

Figma не должна моделировать API. В Figma фиксируется потребительский интерфейс данных: название, цена, изображения, характеристики, наличие, варианты и состояния. Источник этих значений остаётся InSales.

Изменения API/данных должны рассматриваться как отдельная техническая задача и не смешиваться с визуальной стандартизацией.

Webhooks и серверную интеграцию не добавляем в тему только ради визуальной задачи.
