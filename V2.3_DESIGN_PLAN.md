# Veles Legs V2.3 — Design & Implementation Plan

## Goal
Transform the existing V2.1 homepage into a visual story about a real manufacturer: material → product → new direction → calculation → custom production → B2B → proof of manufacturing.

## Non-negotiable rules
- Do not touch the production store or `index.liquid`.
- Do not destroy or rewrite the existing calculator logic unless a separate, explicitly approved fix is required.
- Preserve all working calculator IDs, fields, validation, and mail/request behavior.
- Do not invent company facts, production numbers, capacities, lead times, certifications, or claims.
- Real photography must be supplied by the owner or sourced from an explicitly approved source. Do not present stock/generated imagery as real company photography.
- First implementation pass uses approved image slots/placeholders where real photos are unavailable.
- Every visual change must be isolated to the V2.3 working branch and reviewed by diff before merge.

## Visual direction
Industrial premium + human workshop.
- Airy layouts.
- Large editorial typography.
- Black / warm white / natural wood / metal.
- Real close-up photography.
- Thin technical annotations, dimensions, labels and section numbers.
- Minimal, restrained motion.
- Manufacturing details are visual proof, not decoration.

## Page architecture
1. HERO — “Опоры, которые держат мебель.”
   - Full-width real product/interior photograph.
   - Large editorial headline.
   - Small technical line: ДЕРЕВО · МЕТАЛЛ · НЕСТАНДАРТНЫЕ РЕШЕНИЯ.
   - Thin engineering annotations over the image.

2. INTRO / TASK
   - Transition from emotion to engineering.
   - Main idea: “Мы начинаем не с товара. Мы начинаем с задачи.”
   - Three visual fragments: material / form / load.

3. CATALOG
   - Replace generic equal cards with photographic product categories.
   - Large WOOD and METAL cards.
   - NEW ITEMS as a smaller supporting element.
   - Full catalog CTA as a strong black strip.

4. VELES LIGHT
   - Dark visual break.
   - Real lamp photograph in a dark environment.
   - Technical dimension graphics around the object.
   - Keep this block visually distinct from the rest of the page.

5. CALCULATOR
   - Clean engineering-tool presentation.
   - White/light background.
   - Strong hierarchy around material / form / dimensions / quantity.
   - Optional technical silhouette/diagram, not cartoon 3D.
   - Calculator behavior must remain intact.

6. CUSTOM PRODUCTION
   - Large real manufacturing photograph.
   - Message: “Если стандартной опоры нет — сделаем её.”
   - Show the chain: drawing → production → finished part.
   - Technical labels: ЧЕРТЁЖ / РАЗМЕРЫ / ПРОТОТИП / ПАРТИЯ.

7. B2B
   - More restrained, business-oriented visual language.
   - Use only verified capabilities instead of invented numbers.
   - Possible pillars: МЕЛКИЕ ПАРТИИ / ОПТОВЫЕ ПОСТАВКИ / ПРОИЗВОДСТВО ПОД ЗАКАЗ.
   - Real packaging/finished-batch photograph if available.

8. WHY VELES LEGS
   - Final proof section, not a generic CTA.
   - Large manufacturing/product image.
   - Main message: “Производитель, а не просто магазин.”
   - Three proof points: оборудование / конструкторское бюро / собственное производство.

## Motion
- Slow image reveal.
- Technical lines draw in subtly.
- Section numbers appear on entry.
- Small hover response on product cards.
- No excessive looping animations, bouncing buttons, or decorative motion.

## Implementation order
1. Audit current working file and calculator boundaries.
2. Preserve the working calculator as an untouched protected region.
3. Create the V2.3 visual shell around the existing functional content.
4. Rebuild blocks 1–8 one at a time.
5. Add image slots and technical overlays.
6. Validate Liquid/HTML/CSS/JS structure.
7. Run static checks for duplicate IDs, scripts, calculator selectors and unexpected file changes.
8. Produce a diff for review.
9. Only after approval create/merge the final PR.
