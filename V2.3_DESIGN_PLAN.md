# Veles Legs V2.3 — Design & Implementation Plan

## Objective
Turn the homepage into a visual story about a real manufacturer: material → product → new direction → calculation → custom production → B2B → proof of manufacturing.

## Owner inputs
- Real photos of products, materials, workshop/production, drawings, packaging and Veles Light when available.
- Final confirmation of factual B2B claims and any numeric production metrics.
- Final visual approval before merge.

## Agent responsibilities
- Work only in the dedicated V2.3 branch.
- Treat the current uploaded 3549-line file as the working baseline.
- Preserve the calculator DOM, IDs, fields and JS unless explicitly asked to fix a specific bug.
- Do not invent company facts, capacities, prices, certifications or performance claims.
- Use real-photo slots/placeholders until approved assets exist.
- Keep changes isolated and produce a diff and validation report.

## Design language
Industrial premium + human workshop. Airy layouts, large editorial typography, black/warm-white/natural-wood/metal palette, real photography, thin technical annotations, section numbers, restrained motion.

## Page 1 — Hero
Full-width real product/interior photo. Large headline “Опоры, которые держат мебель.” Small line “ДЕРЕВО · МЕТАЛЛ · НЕСТАНДАРТНЫЕ РЕШЕНИЯ”. Thin dimension/engineering annotations. Strong first impression: manufacturer, not marketplace.

## Page 2 — Intro / task
Transition from emotional hero to engineering. Main idea: “Мы начинаем не с товара. Мы начинаем с задачи.” Three visual fragments: material / form / load.

## Page 3 — Catalog
Large photographic WOOD and METAL entries. NEW ITEMS as a smaller supporting item. Full catalog as a strong black strip. Avoid three identical generic cards.

## Page 4 — Veles Light
Dark visual break. Real lamp photo in a dark environment. Large VELES LIGHT title. Thin technical dimensions and object annotation. Distinct visual rhythm from the main catalog.

## Page 5 — Calculator
Clean engineering-tool presentation on a light background. Clear hierarchy: material / form / dimensions / quantity. Optional technical silhouette, never cartoonish. Calculator functionality remains protected.

## Page 6 — Custom production
Large real workshop/production photo. Main message “Если стандартной опоры нет — сделаем её.” Show drawing → production → finished part. Technical labels: ЧЕРТЁЖ / РАЗМЕРЫ / ПРОТОТИП / ПАРТИЯ.

## Page 7 — B2B
Stricter business visual language. Use only verified capabilities. Prefer real claims such as small batches / wholesale supply / production to order if confirmed. Real packaging or finished-batch photo.

## Page 8 — Why Veles Legs
Final proof section instead of generic CTA. Large production/product image. “Производитель, а не просто магазин.” Three proof points: equipment / engineering bureau / own production.

## Motion
Slow image reveal, subtle technical line drawing, section-number reveal, restrained hover response. No decorative bouncing, endless loops or visual noise.

## Implementation sequence
1. Baseline audit.
2. Protect calculator region.
3. Rebuild visual shell.
4. Implement blocks 1–8 one at a time.
5. Add image slots and technical overlays.
6. Validate Liquid/HTML/CSS/JS.
7. Check duplicate IDs/scripts and calculator selectors.
8. Review diff.
9. Only then merge.
