# 3. ПРОВЕРКА №2 — restoreHomepageHero()

## ❌ FAILED

Функция **не удалена и не пустая**.

Фактическое содержимое `theme.js`:

```javascript
function restoreHomepageHero(root) {
  if (!root || !root.querySelectorAll || !isHomepage()) return;

  root.querySelectorAll('.vl-v2-hero h1').forEach(function (heading) {
    heading.style.setProperty('font-size', 'clamp(54px, 8vw, 104px)', 'important');
    heading.style.setProperty('line-height', '0.9', 'important');
    heading.style.setProperty('letter-spacing', '-3px', 'important');
  });
}
```

Функция вызывается после `DOMContentLoaded`:

```javascript
restoreHomepageHero(document);
```

и также из `MutationObserver` для добавленных DOM-узлов.

Причина в комментарии прямо названа: глобальный `theme.scss` задаёт `h1 !important`, а JavaScript «восстанавливает» размеры Hero. fileciteturn453file0L2-L11

### Вывод

**HIGH:** Hero всё ещё зависит от JavaScript-компенсации CSS.

Это прямо противоречит целевой архитектуре, где CSS должен отвечать за визуал, а JS — за поведение.

# 5. ПРОВЕРКА №4 — SEO / PRODUCT SCHEMA / META / OG

## 5.1 Product Schema

`product.liquid` содержит `Product` + `AggregateOffer` JSON-LD.

Положительная часть:

```json
"@type": "Product"
```

используются `name`, `description`, `sku`, `brand`, `manufacturer`, `offers`, `image`, `additionalProperty`.

Но имеются семантические риски:

```liquid
"lowPrice": "{{ product.variants.first.price ... }}",
"highPrice": "{{ product.variants.last.price ... }}",
"availability": "{% if product.variants.first.available %}..."
```

Код **не доказывает**, что `first` и `last` варианты являются минимальной/максимальной ценой и что availability первой версии репрезентативен для `AggregateOffer`.

Фактическое schema содержимое подтверждено текущим `product.liquid`. fileciteturn456file0L2-L10

### Verdict

**MEDIUM/HIGH:** schema syntactically formed, but semantic correctness of aggregate price/availability is not guaranteed by current code.
